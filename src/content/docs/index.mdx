## Why Choose OSPOS vs Proprietary POS Systems?

| Feature | Open Source Point of Sale | Typical Proprietary Cloud POS (Square, Clover, Lightspeed) |
| :--- | :---: | :---: |
| **Software Cost** | **$0 (Free & Open Source)** | $60 to $250+ / month *per register* |
| **Payment Processor Lock-in** | **None** (Use any bank or card terminal) | Locked into high-fee proprietary processing |
| **Data Privacy & Ownership** | **100% Your Data** on your server | Stored on third-party cloud servers |
| **Offline / Local Network** | **Works on Local Network** (even without internet) | Degrades or fails when internet drops |
| **Hardware Compatibility** | **Any standard ESC/POS printer, scanner, drawer** | Expensive proprietary hardware locked to vendor |
| **Customizability** | **Full Source Code Access** (PHP / CodeIgniter 4) | Closed source, zero code modifications |
| **Multi-Location Inventory** | **Built-in & Unlimited** | Often locked behind expensive enterprise tiers |

## Quickstart in 60 Seconds with Docker

Deploy OSPOS on any Linux, Windows, or macOS workstation with Docker Compose:

```bash
# 1. Download the production docker-compose file
curl -O https://raw.githubusercontent.com/opensourcepos/opensourcepos/master/docker-compose.yml

# 2. Create the configuration secret file
touch .env

# 3. Launch OSPOS and MariaDB
docker compose up -d
```

Open your browser at `http://localhost` and log in with:
- **Username**: `admin`
- **Password**: `pointofsale`

👉 Explore our [Getting Started Guides](/getting-started/overview/) for step-by-step installation instructions for Linux, Windows, and Raspberry Pi.
